# BOATRACE 最終日予想 README

## 目的

初日〜前日までの結果情報と、最終日の出走表情報をもとに、最終日の各レースについて展開予想を行う。

目的は、全レースを買うことではなく、レース展開が読みやすく、買い目を絞れるレースを抽出することである。

## 入力ファイル

### 1. 結果CSV

初日〜前日までのレース結果情報。

主に以下を含む。

- 着順
- 枠番
- 選手ID
- 選手名
- 実際の進入コース
- 実ST
- 決まり手
- 天候
- 風速
- 波高
- 3連単結果
- 払戻

このファイルは、選手ごとの今節傾向、ST傾向、コース別傾向、攻め方・残し方を見るために使う。

### 2. 出走表CSV

最終日の出走表情報。

主に以下を含む。

- 枠番
- 選手ID
- 選手名
- 級別
- F/L
- 平均ST
- 全国勝率
- 当地勝率
- モーター2連率/3連率
- ボート2連率/3連率
- 今節成績
- 早見

このファイルは、最終日の出走メンバー、枠番、機力、選手基礎情報を見るために使う。

## 予想方針

穴狙いを目的にしない。

1号艇中心に固定しない。  
ただし、1号艇のイン信頼度が高い場合は素直に評価する。

1号艇が弱い場合、それだけで見送りにしない。  
2〜6号艇に明確な攻め筋、差し筋、まくり差し筋、展開拾い筋がある場合は買い候補とする。

重要なのは、どの艇が頭かではなく、展開の起点が明確かどうかである。

展開は基本展開.txtを参考にする。

4、5、6号艇頭は、以下が揃わない限り基本やめる

1号艇のイン信頼が明確に低い
2号艇または3号艇が明確に凹む
攻め艇のST優位がサンプル少ではなく継続的
攻め艇が今節で実際にまくり・まくり差しを出している
内側艇の基礎力が弱い

## 展開評価の観点

各レースについて、以下を確認する。

### 1. イン信頼度

1号艇について以下を見る。

- 今節ST
- 今節着順
- 1コース実績
- 全国勝率
- 当地勝率
- モーター気配
- 他艇とのST比較

イン信頼度が高ければ、1頭本線を検討する。  
イン信頼度が低い場合は、2〜4号艇の攻め筋を見る。

### 2. 2号艇の差し・攻め期待

2号艇について以下を見る。

- 今節ST
- 1号艇とのST差
- 2コース実績
- 差し・攻めの傾向
- モーター気配

2号艇が1号艇より明確にST優位、または1号艇が弱い場合は、2頭・2着軸を検討する。

### 3. 3号艇・4号艇の攻め筋

3号艇・4号艇について以下を見る。

- 今節ST
- 内側艇とのST差
- 3コース・4コース実績
- まくり・まくり差しの傾向
- モーター気配

センター勢が内側よりST優位で、かつ機力や着順内容も良い場合は、まくり・まくり差し展開を検討する。

### 4. 5号艇・6号艇の拾い力

5号艇・6号艇について以下を見る。

- 今節の3着以内実績
- 3連率
- モーター気配
- 展開が向くか

外枠は原則として頭よりも2着・3着候補として評価する。  
ただし、明確な攻め筋がある場合は頭候補としても検討する。

## 自信度基準

### A評価

- 展開の起点が明確
- 軸艇の根拠が複数ある
- 相手候補も絞れる
- 買い目が4〜6点以内に自然に収まる
- イン逃げ、差し、まくり、まくり差しのいずれかの展開が説明しやすい

### B評価

- 展開の起点はある
- ただし相手候補に少し幅がある
- 軸は決められるが、本線と押さえの差がやや小さい
- 買うなら少額または押さえ込み

### C評価

- 展開が読みづらい
- STが揃っていて隊形差が出にくい
- 軸候補が複数いて絞りづらい
- モーター差・勝率差が小さい
- 荒れる可能性はあるが説明可能性が低い

C評価は原則として見送り。

## 買い目ルール

買い目は3連単とする。

各レース最大6点まで。

出力は以下に分ける。

- 本線
- 押さえ

本線は1〜3点程度。  
押さえは最大3点程度。

無理に6点出さない。  
展開が読みにくい場合は見送りでもよい。

## 出力形式

各レースについて以下を出力する。

- レース
- 自信度: A/B/C
- 推奨: 買い/見送り
- 展開想定
- 軸艇
- 相手候補
- 本線買い目
- 押さえ買い目
- 根拠
- 不安要素
